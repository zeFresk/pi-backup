Privacy policy: pi-backup

Last updated: 12 November 2026.

  • pi-backup is used by a single person, its owner, to back up their own home server to their own Google Drive.
  • It requests only the drive.file scope: it can access only the files it created itself, not any other file in the Drive.
  • The data it uploads is encrypted on the owner's server before leaving it. Google receives only encrypted files.
  • No personal data from anyone else is collected, stored, shared, sold or used for any other purpose.
  • The OAuth token is stored only on the owner's server and can be revoked at any time from the Google Account permissions page.
